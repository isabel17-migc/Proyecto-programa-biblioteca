AVISO PARA EL PROFESOR: CONEXIÓN A MYSQL

La aplicación se conecta a MySQL con los siguientes datos:

Servidor: localhost
Puerto: 3306
Usuario: root
Contraseña: ["vacía" ]
Base de datos: ["script_biblioteca_0.6.sql"]

La base de datos se crea automáticamente al iniciar el programa.

Si en su computadora el usuario o la contraseña de MySQL son
distintos, visual studio mostrará un aviso de que no pudo conectarse
y se cerrará. No es un error del programa: solo es necesario
cambiar esos datos (respectivamente) en el archivo [conexion.cs], en las líneas :

  12-public static string Servidor { get; set; } = "localhost";
  13-public static uint Puerto { get; set; } = 3306;
  14-public static string BaseDatos = "biblioteca_copia";
  15-public static string Usuario { get; set; } = "root";
  16-public static string Password { get; set; } = "";

(cambiar solo el texto dentro de los "" a el dato que se tiene)
, y volver a ejecutar.

y si esta usando MariaDB de Xampp, porfavor inicializar antes el servicio

Una gran disculpa por la molestia de tener que hacer este ajuste.
